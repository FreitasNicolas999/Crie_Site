# CRIE | Hub de Inovação

O CRIE é uma landing page moderna desenvolvida para apresentar um Hub de Inovação focado em conectar pessoas, tecnologia, educação e empreendedorismo.

O projeto possui uma interface futurista com efeitos visuais avançados, design responsivo e foco na experiência do usuário.

---

## Funcionalidades

- Hero Section Fullscreen
- Glassmorphism
- Background tecnológico animado
- Aurora azul e verde em movimento
- Grid futurista animado
- Contadores animados
- Navbar fixa
- Scroll suave
- Botões com animações de hover
- Cards interativos
- Design responsivo
- Ícones Remix Icons
- Seções institucionais
- Call To Action (CTA)

---

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript Vanilla
- Remix Icons
